# Apple News 日本語まとめ

海外・国内のApple関連メディアのRSSを自動で集め、日本語の見出しと3行程度の要約を付けて
静的サイトとして公開するツール。GitHub Actions が6時間ごとに走り、GitHub Pages が更新される。

- サイト: https://mifune39428.github.io/apple-news-jp/
- 更新: 日本時間の 3時 / 9時 / 15時 / 21時（GitHub Actions の cron）

## しくみ

```
RSS 14媒体 ──> collect.py ──> Gemini(→Groq→Claude→OpenAI) ──> docs/articles.json ──> GitHub Pages
              重複除去・期間絞り込み   見出し翻訳＋独自要約＋分類        静的サイトが読む
```

- 原文の本文は保存も掲載もしない。持つのは**日本語の見出し・独自要約・解説・出典名・原文リンク・サムネイル**。
- 記事ごとに詳細ページ（`docs/a.html?id=...`）があり、原文を読まなくても分かる
  **要点3〜5個＋800〜1200字の日本語解説**を載せる。全訳ではなく、原文をもとに書き起こしたもの。
- 原文そのものを日本語で読みたい場合は、詳細ページの「原文を日本語で全文読む」から
  Google翻訳を通した原文ページが開く（こちらの著作物としては保持しない）。
- サムネイルはRSS内の画像（`media:thumbnail` / `enclosure` / 本文の最初の `<img>`）を使い、
  見つからない記事だけ元ページの `og:image` を取りに行く（実際に載せる記事のみ）。
- LLMがApple無関係と判断した記事（Daring Fireball の雑記など）は自動で落とす。
- どのLLMも使えなかった分は保存せず、次の実行で拾い直す（生煮えの記事を出さないため）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `collect.py` | 収集・重複除去・日本語化・`docs/articles.json` の書き出し |
| `feeds.json` | 収集元のRSS一覧（`enabled: false` で一時停止できる） |
| `llm_providers.py` | LLMの多段フォールバック（dual_draft_poster からのコピー） |
| `docs/index.html` | サイト本体（依存なしの1ファイル、PWA対応） |
| `docs/articles.json` | 一覧用の生成データ。Actions が自動コミットする |
| `docs/a.html` | 記事の詳細ページ（`?id=` で `docs/articles/<id>.json` を読む） |
| `docs/articles/` | 記事ごとの解説データ。一覧から消えた記事のファイルは自動削除される |
| `.github/workflows/update.yml` | 6時間ごとの自動実行 |
| `更新.command` | Mac から手動で即更新（ダブルクリック） |

## 設定

- **GitHub Secrets**: `GEMINI_API_KEY` は必須。`GROQ_API_KEY` を入れておくとGeminiの無料枠が切れても止まらない。
  `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` は任意。
- **ローカル実行**: このフォルダの `.env` に同じキーを書く（gitignore 済み）。

## 調整しどころ（`collect.py` の定数）

- `INTAKE_DAYS = 3` — 何日前までの記事を取り込むか
- `MAX_NEW_PER_RUN = 40` — 1回の実行で日本語化する上限（無料枠を使い切らないための蓋）
- `BATCH_SIZE = 5` — 見出し・要約をまとめて作るときの記事数（Groqの分間トークン制限に合わせてある）
- `MAX_DETAILS_PER_RUN = 25` — 1回の実行で作る解説の本数（1記事につきLLMを1回使う）
- `DETAIL_WORKERS = 3` — 解説生成の並行数
- `KEEP_DAYS = 30` / `KEEP_MAX = 400` — サイトに残す期間と件数

収集元を増やすときは `feeds.json` に足すだけでよい。`lang` が `ja` の媒体は翻訳せず要約だけ作る。

## 著作権について

各記事の権利は出典元にある。このサイトが持つのは自動生成した日本語の見出し・要約・解説、
出典名、原文へのリンクだけで、本文の全訳や転載はしない。
解説は原文を読んで書き起こした要約であり、逐語訳にならないようプロンプトで縛っている。掲載停止の依頼があれば
`feeds.json` から該当媒体を外す。

## 上のメニューの出し入れと、お気に入り（`docs/ui.js`）

`docs/ui.js` は**6つのニュースサイトで同じものを使っている共通ファイル**。

- **下にスクロールすると上のメニュー（見出し＋絞り込み）が隠れ、一番上に戻すと出る。**
  隠すのは見出しの高さを過ぎてから、戻すのは一番上に着いたときで、しきい値を分けて
  境目でちらつかないようにしている。
- **記事カードの右上の ☆ を押すとお気に入りに入り、「★ お気に入り」タブでまとめて読み返せる。**
  タブは絞り込みの1段目、「すべて」のすぐ隣に入る（末尾に足すと横スクロールの外に出て気づかれない）。
  詳細ページ（`a.html`）にも「☆ お気に入り」が出る。

ページ側に足してあるのは次の4つだけ。

| 場所 | 中身 |
| --- | --- |
| `<head>` | `<script src="ui.js" data-site="apple-news-jp"></script>`（**`defer` を付けない**） |
| `render()` | 記事カードを `<article data-id="${escapeHtml(item.id)}">` にする |
| `load()` | `all = window.NEWS_ITEMS = data.items || [];` |
| リンクの決め方 | `window.NEWS_LINK`（お気に入り一覧も同じリンク先を使うため） |

**気をつけること:**

- **`ui.js` は6サイトに同じ内容のコピーが置いてある。** 直すときは全部に配り直す。
  数え方は `md5 -q */docs/ui.js | sort -u | wc -l`（1なら揃っている）。
- **`data-site` を必ず入れる。** お気に入りは localStorage に持っていて、6サイトとも
  `mifune39428.github.io` の同じドメインにあるため、これが無いと互いのお気に入りが混ざる。
  URLから機械的に決めると、一覧（`/`）と詳細（`/a.html`）で別のキーになってしまう。
- **`<script>` に `defer` を付けない。** 付けると、詳細ページの `fetch` のほうが先に終わったときに
  `uiAttachDetail` がまだ無く、お気に入りボタンが付かないことがある。
  画面をいじる処理は `DOMContentLoaded` まで待つので、`<head>` に置いても表示は遅くならない。
- **お気に入りは記事のIDではなく記事そのものを写して持つ。** 一覧は30〜45日で入れ替わるので、
  IDだけ覚えても後から中身が引けない。入れ替わりで消えた記事は「掲載終了」と出し、
  解説ページではなく元記事へのリンクにする。

### 端末をまたぐお気に入りの同期（GitHub Gist）

お気に入りは各ブラウザの localStorage に入るので、そのままでは端末をまたげない。
**GitHub の非公開Gist 1個**に預けて、iPhone でも Mac でも同じ★が出るようにしてある。

- 端末ごとに1回だけ、`gist` 権限のトークンを「★ お気に入り」タブ →「ほかの端末と共有する」から貼る。
  トークンは**6サイト共通**（同じドメインなので分けても意味がない）。1回入れれば6サイトに効く。
- Gist は**説明文の目印 `newsfav-sync` で探す**。Gistのidを持ち歩かなくていいので、
  新しい端末はトークンを貼るだけで既存のGistを見つけられる。6サイトぶんを
  `favorites-<repo名>.json` という別ファイルで1つのGistに入れる（PATCHで自分のファイルだけ触る）。
- **消したことも覚えておく**（`removed` に消した時刻）。これが無いと、片方の端末で外した★が
  もう片方の端末の古い控えで復活する。付け直した時刻のほうが新しければ★は残る。
  墓標は180日で捨てる。
- 送る前に必ず読んでから混ぜる（read-modify-write）ので、2台で同時に触っても片方が消えない。
  取りに行くのは「開いたとき」「戻ってきたとき」「★を押した1.2秒後」。
- 圏外でも★の付け外しは手元で動き、つながったときにまとめて送られる。
- トークンを使いたくないときは、設定画面の「トークンを使わずに手で移す」から
  文字列をコピーして別の端末に貼る。

**トークンの置き場所について:** `mifune39428.github.io` に置いたページからはどれでも読める
localStorage に入る。`gist` 権限だけ・期限付きのトークンを使うこと。要らなくなったら
GitHub 側で失効させれば、その端末の登録も無効になる。
